# Surlap 디자인 프로토타입 (웹앱)

`surlap 디자인.zip` 핸드오프 번들을 그대로 웹앱으로 올린 것이다. 앱 전체 **30개
화면**의 고해상도 목업이 브라우저에서 실제로 동작한다 — 화면을 넘겨보고, 라이트/
다크·언어·로그인 상태·사용자 유형을 바꿔가며 조건부 상태를 확인할 수 있다.

## 화면 구성

| 영역 | 내용 |
| --- | --- |
| 왼쪽 | 화면 목록 30개 (9개 그룹: 첫 실행 · 홈 · 캘린더 · 일정 · 할 일 · 학교 · 기록 · 공유 · 설정) |
| 가운데 | 폰 목업 (412 × 896 dp, Android 기준) |
| 오른쪽 | 화면별 스펙 노트 — 동작 규칙, 상태, 엣지케이스, 알려진 한계 |
| 위 | 전역 스위처 — 테마 · 언어 · 세션 · 사용자 유형 |

스위처가 화면 내용을 실제로 바꾼다. 학교 기능은 사용자 유형이 초·중·고일 때만,
공유 기능은 로그인 상태일 때만 나온다.

## 로컬에서 열기

`file://` 로 직접 열면 `support.js` 의 모듈 로딩이 막히므로 정적 서버로 띄운다.

```sh
cd docs/prototype
python -m http.server 8000
# http://localhost:8000
```

## 파일

| 파일 | 내용 |
| --- | --- |
| `index.html` | 30개 화면 전체 + 화면별 스펙 노트(`NOTES` 상수) |
| `support.js` | 목업 런타임. React 18 UMD 를 자체적으로 불러온다 |
| `ds/` | 목업이 참조하는 기본 스타일시트. 원본 번들에서는 `_ds/` 였는데, GitHub Pages 의 Jekyll 이 `_` 로 시작하는 폴더를 통째로 빼 버려 이름에서 밑줄을 뺐다(같은 이유로 그 안의 `_ds_bundle.js` 등도 밑줄 제거). `index.html` 의 참조 경로도 함께 고쳤다 |
| `HANDOFF.md` | 디자인 토큰·컴포넌트·화면별 규칙 전체 문서 |

## 네트워크 의존

전부 CDN 에서 받아오므로 오프라인에서는 서체·아이콘이 빠진 채로 뜬다.

- React 18.3.1 (unpkg) — 런타임이 로드
- Phosphor Icons 2.1.1 (unpkg)
- Pretendard Variable v1.3.9 (jsDelivr)

## 이 폴더의 위치

디자인 참조용 프로토타입이다. 실제 제품은 저장소 루트의 Flutter 앱이고, 이 목업의
디자인은 거기에 이식되어 있다. 두 곳의 값이 어긋나면 `HANDOFF.md` 가 기준이다.
